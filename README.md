# Operating Systems

A collection of Operating Systems lab programs and practical implementations written in C.

This repository contains coursework and experiments covering core operating system concepts, algorithms, and system behavior.

## Topics

- **CPU Scheduling:** FCFS, SJF, SRTF, HRRN, Round Robin, and Multilevel Queue
- **Process Synchronization:** Locks, Peterson's algorithm, and turn-based synchronization
- **Memory Management:** Paging
- **C Programming:** Fundamental programs and lab exercises

## Getting Started

Clone the repository:

```bash
git clone https://github.com/RISHABH12005/OS.git
cd OS
```

Navigate to the lab folder containing the C program you want to run, then compile it with GCC:

```bash
gcc program.c -o program
./program
```

Replace `program.c` with the source file name.

## Requirements

- GCC compiler
- Linux, Unix-like environment, or another environment with a compatible C compiler

## Purpose

This repository is a practical reference for exploring Operating Systems concepts, implementing algorithms, and learning through hands-on C programming.
